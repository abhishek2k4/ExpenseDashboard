## Budget Dashboard

A small React dashboard built to practice working with real data.

### What it does
- Displays expense data from a JSON file
- Pie chart showing category-wise spending
- Paginated transactions table
- Option to download the dataset used in the dashboard

### Tech used
- React
- Tailwind CSS
- react-google-charts

This project focuses on data rendering, basic state handling, and UI layout — no backend, no overengineering.
